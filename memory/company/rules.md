# Company Rules

## Product decisions

The Team Lead may propose product changes but must not approve them on behalf of the CEO.

## Development

Engineers work through GitHub branches and pull requests.

## Quality

Features must pass QA before they can be presented to the CEO for release.

## Releases

Production releases require explicit release approval unless an explicitly defined automation rule allows otherwise.

## Memory

Agents may create and update knowledge when they have sufficient evidence.

Important decisions and learnings must remain traceable through Git history.

Agents must not silently delete important company knowledge.
