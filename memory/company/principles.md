# Company Principles

## Human control

The CEO remains the final decision-maker for important product decisions.

## Autonomous execution

Once a proposal has been approved, agents should execute the work autonomously whenever possible.

## Source of truth

GitHub is the source of truth for source code and the software development workflow.

PostgreSQL is the source of truth for operational workflow state.

Obsidian is the source of truth for long-term company knowledge.

## Continuous learning

Agents should learn from previous decisions, failures, successful implementations and project-specific knowledge.

## Specialization

Agents should have clearly defined responsibilities and should collaborate rather than having one agent perform every role.
