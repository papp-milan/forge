# Forge character sketches

These are **original Forge character concepts** for the six visible workforce roles. They explore a more expressive comic/anime direction than the production dashboard currently uses.

The dialogue treatment deliberately uses an angled black/red/white comic conversation-panel language inspired by stylish Japanese game UI, while keeping the characters, copy, symbols, and compositions original.

## Directions

- **Athena** — decisive strategist / product lead
- **Hephaistos** — physical builder / engineering
- **Artemis** — precise reviewer / QA
- **Apollo** — expressive designer / UI/UX
- **Nike** — energetic release operator
- **Atlas** — heavier infrastructure operator

The production UI should eventually translate these character identities into reusable portraits, status poses, dialogue moments, and animated agent states rather than embedding the sketches directly into the dashboard.
